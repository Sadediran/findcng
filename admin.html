How to handle a listing report

  1. Open the listing from the report and check what the user says is wrong.
  2. Where the report is right, fix the listing in the master dataset (~/workspace/cng-project/data/stations.json), re-run build-data.py, and redeploy.
  3. Then mark the report resolved here (with a note) — resolving here only closes the report, it does not change the listing.
  4. Dismiss reports that are wrong or abusive, with a note saying why.
